# library

What juke-box knows about albums, songs and MiniMax Music 3. Each page names its sources and marks claims that rest only on blogs. The `album` skill (`../.claude/skills/album/SKILL.md`) reads these pages at each step.

| Page | Use it for |
|---|---|
| `album-craft.md` | Track order, arc shapes, concept and mood albums, interludes, words for feel. Built on two studies of album sequencing. |
| `album-formats.md` | Single, EP or album; song and album lengths by genre; render time per album size. |
| `genres.md` | Tempo, form and delivery per genre; lyric craft; lyric rules for MiniMax. |
| `genre-stats.md` | Tempo, key, mode and singer counts per style family over MiniMax's 1,000 caption templates. Generated by `../scripts/template_stats.py`. |
| `minimax-prompting.md` | Caption format, controls, limits, measured output, one voice across an album, community workarounds. |
| `finishing.md` | Loudness, gaps, tags and the disclosure duty. |

The raw research notes behind these pages are in `../research/`.

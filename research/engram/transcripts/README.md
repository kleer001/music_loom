# Engram transcripts

Speech in the Engram videos cited by `../DIGEST.md`, transcribed locally with Whisper large-v3 (faster-whisper, English, voice-activity filter on). Each line starts with the time in seconds. These are machine output: Whisper writes "Engram" as "Ngram", and the digest quotes a line only where the screen or a caption confirms it. Re-running Whisper gives different text, so these files are the record the quotes rest on.

| File | Source |
|---|---|
| `campaign.txt` | Kickstarter campaign video, <https://www.kickstarter.com/projects/evmaki/engram-generative-audio-sampler-and-groovebox> |
| `blog_*.txt` | Demo videos in the maker's post, <https://evanking.io/posts/engram/> (`/images/mirage/<name>.mp4`) |
| `yt_<id>.txt` | YouTube video `<id>` on <https://www.youtube.com/@thoughtful.things>. Videos with no speech have no file. |
